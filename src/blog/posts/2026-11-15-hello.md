This is a starter post. It is marked `draft: true`, so it shows up when you run
the site locally but is not published.

To write a post, add a Markdown file to `src/blog/posts/` named
`YYYY-MM-DD-some-slug.md` with a `title` at the top. Remove the `draft` line
when it is ready to go live.

## Formatting

Regular Markdown works: **bold**, *italics*, [links](https://example.com),
lists, and images.

> Block quotes look like this.

```python
print("and code blocks look like this")
```
